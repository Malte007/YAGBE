01 Was YAGBE kann

♪

Originalgetreuer Ton

Alle vier Soundkanäle des Game Boy, ausgegeben über OpenAL.

✚

Controller

Xbox-, PlayStation- und andere Gamepads werden erkannt. Tasten frei belegbar.

▦

Farbthemen

Vom klassischen DMG-Grün bis Kirokaze oder Ice Cream, eigene Paletten inklusive.

◆

Save States

Jederzeit speichern und laden: Schnellspeicher plus zehn Slots mit Uhrzeit im Menü Save States. F5 speichert, F8 lädt, F6/F7 wechseln den Slot, am Controller RB/LB/X/Y. Tasten frei belegbar.

▣

Vollbild

Mit F11 ins Vollbild, scharfe Pixel ohne Weichzeichner.

◎

Überall

Windows, Linux und macOS (Intel und Apple-Chip). Nichts zu installieren.

04 Erster Start

YAGBE ist (noch) nicht bei Microsoft oder Apple registriert. Deshalb fragt dein System beim ersten Start einmal nach.

Windows
  1. ZIP mit Rechtsklick → Alle extrahieren entpacken.
  2. Im Ordner YAGBE die Datei YAGBE.exe starten.
  3. Erscheint „Der Computer wurde durch Windows geschützt“: Weitere Informationen → Trotzdem ausführen.
Linux
  1. ZIP entpacken, z. B. per Rechtsklick → Hier entpacken.
  2. Im Ordner YAGBE die Datei YAGBE starten (Doppelklick oder im Terminal ./YAGBE).
  3. Startet nichts: Rechtsklick → Eigenschaften → Als Programm ausführen erlauben.
macOS
  1. ZIP doppelklicken, YAGBE.app in den Ordner Programme ziehen.
  2. Beim ersten Mal: Rechtsklick auf die App → Öffnen → nochmal Öffnen.
  3. Ab macOS 15: Systemeinstellungen → Datenschutz & Sicherheit → unten Dennoch öffnen.
  4. Hilft beides nicht: im Terminal xattr -cr /Applications/YAGBE.app eingeben, danach startet die App normal.
